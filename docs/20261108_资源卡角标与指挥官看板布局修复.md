# 资源卡日环比角标移入标题行（#38）

## 背景

红尖尖断档当天，资源卡角标从 `↓30` 变成长文案后，同排「指挥官等级」卡被压窄，
三位数等级 `163（77,057/354,350）` 的首位数字被裁掉。魔方的 `未记录` / `数据异常`
走同一条布局路径。

## 为什么没有采用「等宽分配 + 数值省略」

第一版实现用「五卡按 2:1:1:1:1 固定比例分配 + 数值中间省略」来稳定宽度，实测被否决：

- 项目真实度量（Windows / Qt 5.15.11 / 96 DPI / Microsoft YaHei UI，
  `docs/指挥官等级卡预计升级角标方案_20261019.md:36,45,53`）：指挥官数值行 **360 px**，
  卡片需要 **390 px**；
- 2:1 比例在 1280 逻辑宽度下只给指挥官卡 **385 px**（数值区 355 px），**从设计上就不够**，
  1024 下只有 299 px，于是数值必然变成省略号；
- 数值是主信息、角标是次信息，为宽度稳定牺牲数值可读性，方向错误。

## 现状变化（#37 之后）

`services/resource_service.py:310-390` 现在只产出三类角标：

| 角标 | 宽度（14 px） |
| --- | --- |
| 数字 `↓30` / `↑1.2K` | ≈30 px |
| `未记录` | ≈42 px |
| `数据异常` | ≈56 px |

`无法比较` 已不再产生，因此「角标把整行撑爆」的压力从 ~80 px 降到 ≤56 px；
真正的问题只剩「角标和数值抢同一条数值行」。

## 方案

| 层次 | 改动 |
| --- | --- |
| `views/widgets/stat_card.py` | 日环比角标（`setBadge`）从数值行移到**标题行**，紧贴标题；数值行只放数值 |
| `views/widgets/stat_card.py` | 保留 `ElidedLabel`：首选宽度=全文、最小宽度=省略号；**只在窗口窄于内容宽度时**才出现省略号，并给全文 tooltip |
| `views/widgets/stat_card.py` | 角标保留宽度上限（日环比 96 px、标题胶囊 180 px），超长只在自己格子里省略 |
| `views/widgets/statistics_panel.py` | 指挥官行恢复「按内容宽度排布 + `addStretch` 吸收留白」，去掉等宽分配与 `QSizePolicy.Ignored` |
| `views/widgets/statistics_panel.py` | 资源刷新失败时一并清除日环比角标（`_setResourceError`），避免「错误」旁边残留旧状态 |

视觉上，资源卡从 `4.1K ↓30` 变成「标题行：`红尖尖 ↓30`」，与指挥官等级卡已有的
标题行角标（`预计 27.7 天后升级`）保持同一套排版语言；角标配色语义不变（红涨绿跌灰状态）。

## 宽度预算

沿用上面的真实度量口径：五卡内容宽度之和基线 **876 px**，1024 窗口可用约 **920 px**。

| 状态 | 五卡之和 | 结论 |
| --- | --- | --- |
| 角标在数值行（修复前） | 954 | ❌ 超 34 px，触发挤压/裁字 |
| 角标在标题行 + 数字 / `未记录` | 876 | ✅ 角标完全落进标题行余量 |
| 角标在标题行 + 两张 `数据异常` | ≈894 | ✅ 仍余 ~26 px |

只有窗口窄于内容宽度（约 1000 px 以下）时，数值才会退化为中间省略；
本轮按需求「暂不考虑滚动条」，这一档保持省略兜底，不再出现硬裁首位。

## 验证

```powershell
python -m unittest tests.test_stat_card_layout -v   # 12 项布局回归
python -m unittest discover -s tests                # 全量 676 项通过
```

offscreen 侧（本机 `QFontDatabase().families()` 为空，回退字体把 ASCII 也按全角绘制，
宽度约为真实字体的 1.8 倍）：

- 内容宽度 1216 px 时，五卡分别 566 / 202 / 90 / 146 / 146 px，全部等于自身首选宽度，
  数值完整（无省略号）；
- 1280 px 宽下五卡仍保持各自首选宽度，角标 `未记录` / `数据异常` 完整显示；
- 800 px 宽下所有可见文字都满足「文本宽度 ≤ 标签可用宽度」，卡片不重叠。

测试覆盖：角标位于标题行、角标文案变化只影响自己那张卡、内容宽度下数值不省略、
窄窗口省略而非硬裁、角标与标题角标宽度封顶、错误态清角标。

## 待人工确认

- 真实字体下 1024 / 1280 / 1366 / 1920 逻辑宽度：数值完整、无省略号，三位数等级首位可见；
- 角标移动到标题行后的观感（`红尖尖 ↓30` / `魔方 未记录`）是否符合预期；
- 若窗口常驻在 1024 以下，需要再谈「横向滚动 / 提高最小窗口宽度 / 数值缩字号」三选一。
