# 时间刷新方案（2026-10-19）

> 关联 issue：[#24 时间相关控件跨天不刷新](https://github.com/laihongyu-demo/AzurLaneTool/issues/24)
> 状态：已实现（`feature/time-refresh`）
> 范围：记账日期、常规录入时刻、指级经验时间 / 查询区间、数据看板执勤天数

---

## 1. 问题与原则

跨天或长时间运行后，控件仍停留在构造时的日期 / 时刻，写入路径又直接信任控件值，导致任务和收支被记到昨天。

落地时遵循两条原则：

1. **写对优先于显示对**：即使 UI 没有及时刷新，写入也必须落在正确的日期 / 时刻；
2. **刷新按需**：切页、零点、窗口激活只做「时间上下文检查」，同日不查库、不重算结余链。

---

## 2. 自动态 / 手动态

统一用「哨兵值」区分，不额外加复选框：

| 场景 | 自动态（未手动改过） | 手动态（用户改过） |
| --- | --- | --- |
| 常规录入时刻 | 控件值 == 上次自动设置值；写入用点击瞬间的 `now()` | 保留所选时刻，写入用所选值 |
| 记账日期 | 控件值 == 上次自动日期；完成任务用 `today()` | 保留所选日期，作为补录归属日 |
| 指级经验时间 | 同上；打开窗口 / 跨天时前进 | 保留所选时刻 |
| 查询区间 | 起始 / 结束日各自独立；未改过则随今天平移 | 改过的一端不再自动跟随 |

**关键点**：跨天时自动态写入用「点击瞬间」而不是控件旧值；因此即使 `onActivated` 没触发，也不会写错。程序化设置控件时不计入手动态。

---

## 3. 刷新触发矩阵

| 触发 | 行为 | 成本 |
| --- | --- | --- |
| 页签 `currentChanged` | 只调用当前页 `onActivated()`：同步自动态时间；日期变了才刷新当前页 | 同日 0 连接；跨天资源页约 13 ms / 7 连接 |
| 看板「刷新」按钮 | 同步时间后只重渲染本地看板，**不再** `emit dataRefreshed` 触发统计全量刷新 | 约 13 ms / 7 连接（原 79 ms / 22） |
| 菜单「刷新」/ Ctrl+R | 同步三页时间上下文后全量刷新 | 约 232–253 ms / 30 连接（保留原语义） |
| 午夜单次 `QTimer` | 到下一个 00:00 后触发当前页 `onActivated()`，再排下一次 | 1 次/天，调度 <1 ms；跨天时最多一次 13 ms |
| 窗口重新激活 / 休眠恢复 | 先同步当前页时间（µs 级）；只有跨天才触发数据刷新 | 日期比较 + 控件同步，0 连接 |
| 指级经验窗口 `showEvent` | 同步自动态时间 / 查询区间，重新载入最近记录；编辑中不重置 | 一次列表查询 |

**不做**：每秒轮询、每次切页全量刷新、为「看起来在动」重扫结余链。

数据看板跨天更新「执勤天数」与两张资源卡角标（#25：数字角标要切换为「未记录」）；魔方 / 红尖尖的结余本身仍以最新记录为右端点，没有新数据时不变。

## 4. 性能预算与实测

数据：`resource_daily` 1,829 行、`resource_transaction` 7,174 行；offscreen、5 次中位数。

| 路径 | 目标 | 实测 |
| --- | ---: | ---: |
| 同日切页（三个页签） | 0 连接 | 0.00 ms / 0 |
| 跨天首次进资源统计 | ≤ 30 ms / ≤ 11 连接 | 12.2–14.9 ms / 7 |
| 看板「刷新」按钮 | ≤ 20 ms / 7 连接 | 12.2–13.5 ms / 7 |
| 跨天首次进数据看板 | ≤ 40 ms / 4 连接 | 约 35 ms / 4（含资源卡角标状态切换） |
| Ctrl+R 全量 | 保持现状 | 237–253 ms / 30 |
| 午夜定时器 | 1 次/天 | 调度 <1 ms |
| 时间控件重置 | µs 级 | 约 2–3 µs/个 |

原「每次切页全量刷新」方案的成本是 67 ms（数据看板）/ 17 ms（资源统计）/ 168 ms（舰娘管理）；本方案在同日切页时不付这些成本；跨天时资源统计页约 12–14 ms，数据看板约 35 ms（含角标状态切换），仍远低于三页全量 253 ms。

## 6. 测试

新增 `tests/test_time_refresh.py`（23 例）：

- 常规录入：激活推进、未触碰写入当前时刻、手动态保留、写入后自动态推进；
- 魔方看板：激活推进、未触碰写入新一天、补录保留、「今天」恢复自动跟随、上限为今天、刷新不级联；
- 数据看板：跨天更新执勤天数与资源卡角标、同日激活不查服务；
- 指级经验：时间 / 区间前进、手动态保留、编辑中不重置、未触碰保存按点击瞬间、窗口 `showEvent` 生效；
- 主窗口：页签只激活当前页、窗口激活同步时间且仅跨天重排定时器、午夜定时器只排一次。

运行：

```powershell
$env:QT_QPA_PLATFORM='offscreen'
python -B -m unittest discover -s tests -t .
# Ran 380 tests ... OK
```
