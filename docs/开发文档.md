# 精准经验效率计算算法

## 修订后的正式开发文档（最终版）

**文档版本**：V1\.0（Final）
**算法状态**：可开发 / 可测试 / 可上线
**适用项目**：经验成长系统、效率分析、趋势预测
**适配环境**：

- 数据库：SQLite

- 客户端：Python Qt（PyQt5 / PySide6）

- 计算语言：Python 3\.9\+

- 输出形式：JSON / SQLite 表

---

## 文档目的

本文档用于定义一套**可直接投入生产环境**的“精准经验效率计算算法”，用于：

1. 基于真实经验数据，计算**每日当前经验效率**

2. 在存在漏统计、升级、异常激增/衰减的情况下，仍能保持结果稳定可信

3. 使用 **λ 指数衰减加权法** 预测未来经验效率

4. 输出结构可直接写入 SQLite，并被 Python Qt 客户端调用与展示

5. 具备清晰的数据定义、异常防护、测试与上线规范

## 核心概念定义

---

### 3\.1 当前等级起点累计经验

由于表2中的 `cumulative_required_exp` 表示的是**升级门槛**，
 因此当前等级的起点累计经验定义为：

```Plain Text
level_start_cum_exp(level) =
    0,                          当 level = 1
    cumulative_required_exp(level - 1), 当 level > 1
```

---

### 3\.2 累计总经验（Absolute Experience）

用于消除升级时经验回绕问题。

absolute\_exp = level\_start\_cum\_exp\(level\) \+ current\_exp

> 若未来表1新增字段 `total_exp`（直接存累计经验），
>  算法应**优先使用表1的累计经验字段**，跳过等级换算。
> 
> 

---

### 3\.3 当前效率（Current Efficiency）

表示单位时间内的经验增长速度。

```Plain Text
current_efficiency
= (absolute_exp_t - absolute_exp_t-1) / delta_days
```

单位：经验 / 天

---

### 3\.4 预计效率（Predicted Efficiency）

基于历史效率，采用 λ 指数衰减加权预测未来效率。

```Plain Text
predicted_efficiency
= Σ(adjusted_current_efficiency_i × λ_i) / Σ(λ_i)
```

---

## 总体算法流程

```Plain Text
读取原始数据
    ↓
时间排序 + 同日去重
    ↓
累计总经验换算
    ↓
识别漏统计日期
    ↓
展开为连续自然日
    ↓
计算原始当前效率
    ↓
异常检测（激增 / 衰减 / 回档 / 缺口）
    ↓
效率修正（裁剪 / 降权）
    ↓
指数衰减预测
    ↓
输出 JSON / 写入 SQLite
```

## 数据预处理规则

---

### 5\.1 时间排序

按 `date_time` 升序排序，确保时间连续性。

---

### 5\.2 同日多次记录处理

若同一自然日存在多条记录：

> **仅保留该日最后一条记录**
> 
> 

理由：

- 业务定义为“每日统计一次”

- 最后一条最能代表当日最终状态

---

### 5\.3 数据合法性校验

必须校验：

- `level` 是否存在于表2

- `current_exp ≥ 0`

- `date_time` 格式合法

- 等级是否为正整数

非法数据处理策略：

- 记录错误日志

- 跳过该条数据

- 不中断整体计算流程

---

## 漏统计日期处理（插值）

---

### 6\.1 漏统计识别

若相邻两条记录间：

```Plain Text
delta_days > 1
``
```

则中间存在漏统计日期。

---

### 6\.2 基础插值方式

区间效率定义为：

```Plain Text
interval_efficiency
= (absolute_exp_2 - absolute_exp_1) / delta_days
```

将该效率分配到区间内的每一个自然日。

---

### 6\.3 长缺口修正策略（推荐）

若缺口天数较大（如 \> 3 天），使用混合修正：

```Plain Text
adjusted_efficiency
= α × interval_efficiency + (1 - α) × baseline_efficiency
```

其中：

```Plain Text
α = min(1.0, 2 / delta_days)
baseline_efficiency = 最近 N 天效率中位数（推荐 N = 7）
``
```

---

### 6\.4 插值置信度

```Plain Text
confidence = min(1.0, 2 /
```

- 原始记录：1\.0

- 插值记录：\< 1\.0

## 异常检测与防护机制

为防止激增/衰减严重影响预测，采用**鲁棒统计方法**。

---

### 8\.1 滚动基线（MAD 方法）

基于最近 `N = 7` 天的效率：



baseline = median\(E\)

mad = median\(\|E\_i \- baseline\|\)

robust\_sigma = 1\.4826 × mad

---

### 8\.2 异常上下界



lower\_bound = max\(0, baseline \- k × robust\_sigma\)

upper\_bound = baseline \+ k × robust\_sigma

推荐：

```Plain Text
k = 3.0
``
```

## 趋势切换识别（重要）

---

### 9\.1 触发条件

若满足以下任一条件，判定趋势切换：

- 连续 3 天：

adjusted\_efficiency \< baseline × 0\.6

- 最近 5 天均值 \< 前 14 天中位数 × 0\.65

---

### 9\.2 切换策略

- 缩短预测窗口（如 7 天）

- 降低 λ（如从 0\.9 → 0\.8）

- 标记趋势状态供前端展示

## 预计效率计算

---

### 10\.1 权重定义

最新数据权重最高：

W\_latest = 1

W\_previous = λ

W\_previous2 = λ²

---

### 10\.2 预测公式



predicted\_efficiency

= Σ\(adjusted\_current\_efficiency × W\) / Σ\(W\)

---

### 10\.3 推荐参数
