## 6. Caveats

- 快照是用户手动录入的累计经验，不是等间隔观测；span 与记录频率相关；
- 未来值容差 ±3 天，长跨度会被丢弃，样本随之减少；
- 合成阶跃响应只用一条确定性曲线，衡量的是收敛速度，不是统计精度；
- 趋势信号样本 37 / 31（加速 / 放缓），阈值只作初始值；
- 回测在 Python 内完成，未进入 UI 线程；报告与常量由人复核。
