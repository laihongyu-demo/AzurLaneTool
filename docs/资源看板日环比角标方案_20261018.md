两条关键结论：

1. **"昨日"在现有数据里几乎总是存在**（相邻间隔全部为 1 天），严格按自然日对比可行；
2. **持平并不罕见**（红尖尖 34% 的天数无变化），必须定义持平样式，否则会显示成 `↑0` 或空白。

## 3. 口径定义

### 3.1 推荐口径：严格自然日对比（v1.1）

```
今天 = T
最新有记录日 D = 结余链最后一行

若 D == T：
    若 T-1 也存在日汇总行：
        delta = balance(T) - balance(T-1)
    否则（昨日断档）：
        灰色「无法比较」，tooltip 说明昨日无记录
若 D < T：
    灰色「未记录」，tooltip 保留最近一次日环比明细
若 D > T：
    灰色「数据异常」，提示最新记录晚于今天
```

- 与卡片显示值**同源**：卡片结余就是 `balance(D)`，角标只在 `D == T` 时给出数字；
- 结余链本身已处理明细日 / 汇总日 / 锚点，因此不需要再区分 `detail_mode`；
- 不引入任何新的查询：在现有的 `getBalanceSeries` 结果上取最后两行，并多一次 `today()` 比较（见 §7）。

### 3.2 备选口径（供选择）

| 口径 | 定义 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A. 严格今日（采用）** | 只有 D == T 且 T-1 有记录时给数字；今日无记录显示「未记录」 | 语义最直白，角标只描述今天 | 每天首次记录前不显示数字 |
| B. 较上次记录 | D 与上一个有记录日 | 永远有值 | 若断档 3 天，标签会误读成"一天的变化" |
| C. 较 7 日均值 | D 结余 − 近 7 天均值 | 平滑 | 与"昨日"字面不符，用户难以核对 |
| D. 较今日开始 | 当日净增（收入 − 支出） | 反映"今天赚了多少" | 与"昨日"无关，且多笔记录时需实时算 |

> v1.1 采用 A，并增加「未记录 / 无法比较」灰色状态（#25）。

## 4. 展示设计

### 4.1 文案

| 情形 | 文案 | 颜色 |
| --- | --- | --- |
| 上涨 | `↑111` | 红 `#c62828` |
| 下降 | `↓111` | 绿 `#2e7d32` |
| 持平 | `—` | 灰 `#757575` |
| 今日未记录 | `未记录` | 灰 `#757575` |
| 今日有记录但昨日断档 | `无法比较` | 灰 `#757575` |
| 最新记录晚于今天 | `数据异常` | 灰 `#757575` |
| 无数据（空表 / 缺表） | 不显示 | — |

- 千分符：≤ 9,999 用 `formatExact`（`↑1,111`）；≥ 10,000 用 `formatValue` 缩写（`↑12.3K`），与卡片刻度的缩写口径保持一致；
- 正负号：箭头已表达方向，数值不带 `+/-`；
- 箭头用 `↑` / `↓`（U+2191 / U+2193）；若字体缺字可退回 `^` / `v`。

### 4.2 位置

卡片结构是「标题 / 数值」两行。建议把数值行改为水平布局：

```
魔方
4.1K  ↑10
```

- 角标与数值**基线对齐**、右侧留 8px，卡片总高度不变；
- 不放在标题行，避免与标题抢空间。

### 4.3 tooltip

在现有提示后追加一段，保持可核对：

```
魔方：4,086（末次记录 2026-10-18 17:49:21）｜较昨日 +10（10-17 4,076 → 10-18 4,086）
```

| 情形 | 追加文案 |
| --- | --- |
| 上涨 / 下降 | `｜较昨日 +10（10-17 4,076 → 10-18 4,086）` |
| 持平 | `｜与昨日持平（10-17、10-18 均为 4,076）` |
| 今日未记录 | `｜今日未记录｜最近一次日环比 10-18 +11（10-17 4,076 → 10-18 4,087）` |
| 今日有记录但昨日断档 | `｜今日有记录，但昨日（10-17）无记录，无法比较` |
| 仅今天一天数据 | `｜仅一天记录，无法比较` |
| 最新记录晚于今天 | `｜最新记录日期 2026-10-20 晚于今天，请检查数据` |
| 锚点日 | 上述文案后加 `（含手填结余）`，提醒该日结余是人为设定 |

### 4.4 与卡片当前值的关系

角标只描述**今天**相对昨天的变化：

- 若今天已录入 → 就是“今天比昨天”；
- 若今天还没录入 → 灰色 `未记录`，不拿昨天的数字冒充今天；tooltip 保留最近一次日环比，供核对；
- 若今天有记录但昨天断档 → 灰色 `无法比较`，不用更早的记录冒充昨天。

## 5. 边界与降级

| 场景 | 处理 |
| --- | --- |
| 无数据（表缺失 / 空表） | 卡片 `-`，不显示角标 |
| 只有今天一天记录 | `无法比较` 灰，tooltip 说明「仅一天记录」 |
| 只有历史一天记录、今天无记录 | `未记录` 灰，tooltip 说明「今日未记录｜仅一天记录」 |
| 今日无记录（D < T） | `未记录` 灰，tooltip 保留最近一次日环比 |
| 今日有记录但昨日断档 | `无法比较` 灰，tooltip 说明昨日无记录 |
| 持平 | `—` 灰 |
| 锚点日（`balance_override` 非空） | 照常计算，tooltip 标注「含手填结余」 |
| 补录 / 撤销 / 删除明细后 | 结余链重算 → 角标自动随之变化（无需额外逻辑） |
| 未来日期的脏数据 | `数据异常` 灰，tooltip 提示检查数据 |

## 6. 实现设计

### 6.1 服务层

```python
@dataclass
class ResourceDailyDelta:
    delta: int                 # 正数上涨、负数下降、0 持平
    latest_date: str           # yyyy-MM-dd
    previous_date: str
    latest_balance: int
    previous_balance: int
    has_anchor: bool           # 两天中是否有手填结余锚点
```

```python
@dataclass
class ResourceCardView:
    text: str
    tooltip: str
    delta: Optional[ResourceDailyDelta] = None   # None 表示没有数字日环比
    badge_text: str = ""                          # 未记录 / 无法比较 / 数据异常 也走这里
    badge_tone: str = ""                          # up / down / flat
```

- `ResourceService.getCardView()` 返回 `ResourceCardView`（**复用同一次结余扫描**，不新增查询）；
- `_buildDailyDelta(series, today)` 由调用方传入今天，便于测试跨天；
- `getCardText()` / `getCardTooltip()` 保留，内部取 `getCardView()` 对应字段（对外行为不变）。

### 6.2 组件层

```python
class StatCard:
    def setBadge(self, text: str, tone: str) -> None:  # tone: up / down / flat
    def clearBadge(self) -> None
```

- 内部一个 `QLabel`，默认隐藏；`tone` 映射到三套 QSS 颜色；
- 数值行改为 `QHBoxLayout`（数值 + 弹性空白 + 角标），卡片高度与现有一致。

### 6.3 面板层

`StatisticsPanel.updateResourceStats()`：

```python
view = self._resource_service.getCardView(resource_type)
card.setValue(view.text)
card.setToolTip(view.tooltip)
badge_text = view.badge_text
badge_tone = view.badge_tone
if not badge_text and view.delta is not None:      # 兼容旧桩
    badge_text = view.delta.display_text
    badge_tone = view.delta.tone
if badge_text:
    card.setBadge(badge_text, badge_tone or DELTA_TONE_FLAT)
else:
    card.clearBadge()
```

跨天时 `StatisticsPanel.onActivated()` 在日期变化后调用一次 `updateResourceStats()`，让数字角标切换为「未记录」；同日切页不调用。

## 7. 性能

- 完全**复用** `getBalanceSeries` 的单次扫描（#14 修复后每资源仅 1 次），角标只是取最后两行做减法；
- 不新增 SQL、不新增连接；
- `updateResourceStats` 实测约 32.3 ms / 4 连接（#24 基准）；
- 跨天时 `StatisticsPanel.onActivated()` 多调用一次 `updateResourceStats`（一天一次，约 32–35 ms / 4 连接）；同日切页为 0。

## 9. 验收标准

- [x] 两张资源卡在数值右侧显示角标，上涨红 / 下降绿 / 持平灰
- [x] 今日有记录且昨日有记录时：角标 = 今日结余 − 昨日结余，可用 tooltip 逐位核对
- [x] 今日无记录：`未记录` 灰，tooltip 含「今日未记录」与最近一次日环比
- [x] 今日有记录但昨日断档 / 仅一天 / 未来数据：`无法比较` / `数据异常` 灰
- [x] 锚点日 tooltip 标注「含手填结余」
- [x] 录入 / 撤销后角标随结余链自动更新
- [x] 跨天激活切换为 `未记录`；同日切页 0 查询
- [x] `updateResourceStats` 的结余扫描次数不增加；全量测试通过
