# 魔方 / 红尖尖卡片「较昨日」角标方案

> 版本 v0.1（**待评审，未实现**）
> 关联：#14（看板四张卡）、#17（资源录入）
> 目标：两张资源卡在结余之外，增加「相较昨日是涨是跌」的标签，例：`⇧111`（红）/ `⇩111`（绿）。

---

## 1. 需求描述

| 项 | 内容 |
| --- | --- |
| 位置 | 「数据看板」的魔方、红尖尖两张卡 |
| 内容 | 最新结余相比昨日的变化量 |
| 方向色 | **上涨红色**、**下降绿色**（A 股习惯，按需求方指定） |
| 示例 | `⇧111`（红）、`⇩111`（绿） |

---

## 2. 数据现状（2026-10-18 实测）

| 项 | 魔方 | 红尖尖 |
| --- | --- | --- |
| `resource_daily` 天数 | 1,173 | 656 |
| 相邻日期间隔分布 | 全部 1 天（1,172 段） | 全部 1 天（655 段） |
| 最近 30 天有记录天数 | 30 / 30 | 30 / 30 |
| 最新结余 | 4,086（10-18） | 3,441（10-18） |
| 前一日结余 | 4,076（10-17） | 3,386（10-17） |
| 当前差值 | **+10** | **+55** |
| 日变化分布 | 涨 1,059 / 跌 108 / 平 5 | 涨 356 / 跌 77 / **平 222** |
| 极值 | +285 / −385 | +6,240 / −5,555 |
| 手填结余锚点 | 5 个（2023 年，均已远离当前） | 1 个（2025-01-01） |

两条关键结论：

1. **"昨日"在现有数据里几乎总是存在**（相邻间隔全部为 1 天），严格按自然日对比可行；
2. **持平并不罕见**（红尖尖 34% 的天数无变化），必须定义持平样式，否则会显示成 `⇧0` 或空白。

## 3. 口径定义

### 3.1 推荐口径：严格自然日对比

```
最新有记录日 D = 结余链最后一行
若 D-1 也存在日汇总行：
    delta = balance(D) - balance(D-1)
否则（断档）：
    不显示角标，tooltip 说明「昨日无记录」
```

- 与卡片显示值**同源**：卡片结余就是 `balance(D)`，角标是它在结余链上的一阶差分，不会出现"卡片 4,086、角标却对不上"的情况；
- 结余链本身已处理明细日 / 汇总日 / 锚点，因此不需要再区分 `detail_mode`；
- 不引入任何新的查询：在现有的 `getBalanceSeries` 结果上直接取最后两行即可（见 §7）。

### 3.2 备选口径（供选择）

| 口径 | 定义 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A. 严格昨日（推荐）** | D 与 D-1 两天 | 语义最直白，与"昨日"字面一致 | 断档时无角标 |
| B. 较上次记录 | D 与上一个有记录日 | 永远有值 | 若断档 3 天，标签会误读成"一天的变化" |
| C. 较 7 日均值 | D 结余 − 近 7 天均值 | 平滑 | 与"昨日"字面不符，用户难以核对 |
| D. 较今日开始 | 当日净增（收入 − 支出） | 反映"今天赚了多少" | 与"昨日"无关，且多笔记录时需实时算 |

> 推荐 A：数据完整度高，且口径可逐日核对（打开任一日的结余就能验证）。

## 4. 展示设计

### 4.1 文案

| 情形 | 文案 | 颜色 |
| --- | --- | --- |
| 上涨 | `⇧111` | 红 `#c62828` |
| 下降 | `⇩111` | 绿 `#2e7d32` |
| 持平 | `—` | 灰 `#757575` |
| 不可比（断档 / 只有一天 / 无数据） | 不显示 | — |

- 千分符：≤ 9,999 用 `formatExact`（`⇧1,111`）；≥ 10,000 用 `formatValue` 缩写（`⇧6.2K`），与卡片刻度的缩写口径保持一致；
- 正负号：箭头已表达方向，数值不带 `+/-`；
- 箭头用 `⇧` / `⇩`（U+21E7 / U+21E9），与需求一致；若字体缺字可退回 `↑` / `↓`。

### 4.2 位置

卡片结构是「标题 / 数值」两行。建议把数值行改为水平布局：

```
魔方
4.1K  ⇧10
```

- 角标与数值**基线对齐**、右侧留 8px，卡片总高度不变；
- 不放在标题行，避免与标题抢空间。

### 4.3 tooltip

在现有提示后追加一段，保持可核对：

```
魔方：4,086（末次记录 2026-10-18 17:49:21）｜较昨日 +10（10-17 4,076 → 10-18 4,086）
```

| 情形 | 追加文案 |
| --- | --- |
| 上涨 / 下降 | `｜较昨日 +10（10-17 4,076 → 10-18 4,086）` |
| 持平 | `｜与昨日持平（10-17、10-18 均为 4,076）` |
| 断档 | `｜昨日（10-17）无记录，无法比较` |
| 仅一天数据 | `｜仅一天记录，无法比较` |
| 锚点日 | 上述文案后加 `（含手填结余）`，提醒该日结余是人为设定 |

### 4.4 与卡片当前值的关系

角标始终描述**最新记录日**相对前一日的变化：

- 若今天已录入 → 就是"今天比昨天"；
- 若最近一次记录是两天前 → 角标是"那天比它的前一天"，tooltip 里的日期会揭示是哪一天，不会误导成"今天的涨跌"。

## 5. 边界与降级

| 场景 | 处理 |
| --- | --- |
| 无数据（表缺失 / 空表） | 卡片 `-`，不显示角标 |
| 只有一天记录 | 不显示角标，tooltip 说明「仅一天记录」 |
| 断档（D-1 缺失） | 不显示角标，tooltip 说明「昨日无记录」（备选：改用 B 口径） |
| 持平 | `—` 灰 |
| 锚点日（`balance_override` 非空） | 照常计算，tooltip 标注「含手填结余」 |
| 补录 / 撤销 / 删除明细后 | 结余链重算 → 角标自动随之变化（无需额外逻辑） |
| 未来日期的脏数据 | 不在本期处理（录入侧已禁止未来时刻） |

## 6. 实现设计

### 6.1 服务层

```python
@dataclass
class ResourceDailyDelta:
    delta: int                 # 正数上涨、负数下降、0 持平
    latest_date: str           # yyyy-MM-dd
    previous_date: str
    latest_balance: int
    previous_balance: int
    has_anchor: bool           # 两天中是否有手填结余锚点
```

```python
@dataclass
class ResourceCardView:
    text: str
    tooltip: str
    delta: Optional[ResourceDailyDelta] = None   # None 表示不可比
```

- `ResourceService.getCardView()` 改为返回 `ResourceCardView`（**复用同一次结余扫描**，不新增查询）；
- `getCardText()` / `getCardTooltip()` 保留，内部取 `getCardView()` 对应字段（对外行为不变）。

### 6.2 组件层

```python
class StatCard:
    def setBadge(self, text: str, tone: str) -> None:  # tone: up / down / flat
    def clearBadge(self) -> None
```

- 内部一个 `QLabel`，默认隐藏；`tone` 映射到三套 QSS 颜色；
- 数值行改为 `QHBoxLayout`（数值 + 弹性空白 + 角标），卡片高度与现有一致。

### 6.3 面板层

`StatisticsPanel.updateResourceStats()`：

```python
view = self._resource_service.getCardView(resource_type)
card.setValue(view.text)
card.setToolTip(view.tooltip)
if view.delta is None:
    card.clearBadge()
else:
    card.setBadge(view.delta.display_text, view.delta.tone)
```

## 7. 性能

- 完全**复用** `getBalanceSeries` 的单次扫描（#14 修复后每资源仅 1 次），角标只是取最后两行做减法；
- 不新增 SQL、不新增连接；
- 预期 `updateResourceStats` 耗时不变（约 31 ms，其中 30 ms 是结余链本身）。

## 9. 验收标准（实现时）

- [ ] 两张资源卡在数值右侧显示角标，上涨红 / 下降绿 / 持平灰
- [ ] 角标数值 = 最新结余 − 昨日结余，可用 tooltip 里的两个数逐位核对
- [ ] 断档、仅一天、空表三种情况不显示角标且 tooltip 说明原因
- [ ] 锚点日 tooltip 标注「含手填结余」
- [ ] 录入 / 撤销后角标随结余链自动更新
- [ ] `updateResourceStats` 的结余扫描次数不增加；全量测试通过
