当前世界巡游期为 `2026-10-01 ~ 2026-11-30`。

- 该区间内没有金额 50 的红尖尖收入记录；

## 4. 迁移建议

### 4.1 可规则迁移

- `amount = 50` → `世界巡游`，55 笔；
- `amount = 500` → `贸易许可证`，22 笔；
- `amount = 250` → `世界巡游`，1 笔（按 5 × 50 聚合）。

### 4.2 迁移前

1. 备份整库到 `data/backup/`；
2. 在副本上执行并核对笔数 / 金额合计；
3. 补类型字典「世界巡游」「贸易许可证」；
4. 迁移后检查 `resource_daily` 不变（本次只改明细 category，不影响日汇总）。

### 4.3 核对 SQL

```sql
-- 迁移前
SELECT amount, COUNT(*), SUM(amount)
FROM resource_transaction
WHERE resource_type = 'red_gem' AND direction = 'income' AND category = '月卡'
GROUP BY amount;

-- 迁移后
SELECT category, COUNT(*), SUM(amount)
FROM resource_transaction
WHERE resource_type = 'red_gem' AND direction = 'income'
  AND category IN ('月卡', '世界巡游', '贸易许可证')
GROUP BY category;
```

## 5. 代价与风险

- 主要风险：250 的聚合口径已由用户确认（5 × 50），不再保留「月卡」明细。
- 迁移不改变总额，只改变分类；`resource_daily` 与结余链不受影响。
